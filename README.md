# Project-REGGIE
This is my project for creating my first AI starting with a very basic to hopefully advanced AI.

## The Goal

The goal of this project is to build it to really understand how AI works. I am using Python to create the backbone of REGGIE and using Ollama's llama3 to actually have the LLM functionality on my own personal machine. Currently, REGGIE can think, conversate, and interact with a system by opening apps and files.
